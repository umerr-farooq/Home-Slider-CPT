# Home-Slider-CPT

This code registers a custom post type (CPT) called "Home Slider" in WordPress and creates a shortcode [homeslider] to display slider items on the front end.

Key Features:
Custom Post Type:

Named homeslider, with UI labels for managing slider content in the WordPress dashboard.

Supports features like title, editor, excerpt, and featured image.

Visible in menus and publicly queryable.

Shortcode Output ([homeslider]):

Fetches all homeslider posts.

Displays each post in a styled slider format with a background image (featured image), title, excerpt, content, and two buttons for external links.

Uses Bootstrap-like layout structure (container, row, col-md-12) for layout styling.

This setup is typically used to create a homepage image slider that can be easily updated from the WordPress admin.
